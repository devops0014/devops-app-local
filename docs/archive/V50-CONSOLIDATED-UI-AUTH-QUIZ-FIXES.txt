Update procedure
1. Keep a safe copy of the current .env.local file.
2. Extract this ZIP into a new folder.
3. Copy the existing .env.local into the new folder.
4. Run: npm install
5. Run: npm run dev
6. Verify homepage, signup, authenticated logo navigation, Practice and Quiz.
7. Deploy only after the local verification succeeds.
