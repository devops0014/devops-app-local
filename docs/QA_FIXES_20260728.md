# Account and QA fixes — 28 July 2026

## Authentication and account

- Increased login and registration field size and font size.
- Replaced the small email-verification message with an accessible confirmation dialog.
- Removed hard-coded student identity from the application shell, dashboard and mock interview room.
- Added account settings for name, mobile number, email display, password update and secure sign-out.
- Sign-out now terminates the Supabase session before returning to the landing page, preventing protected routes from reopening through an old session.

## Application UI

- Notification icon now opens a security-notification centre backed by `security_notifications`.
- Light mode now updates panels, navigation, borders, text, inputs, cards and decorative grids—not only the page background.
- Mobile Question Bank spatial section has more vertical room and horizontally scrollable category controls to prevent overlap.

## Billing and AI

- Monthly allowance: 2 AI mock interviews.
- Six-month allowance: 15 AI mock interviews.
- Yearly allowance: fair usage (internally protected by a high safety ceiling).
- Added migration `2026072801_account_and_ai_limits.sql`; it adds the mobile profile field and applies server-side allowance enforcement.
- Razorpay failures now return the provider’s safe description and clearly identify test/live configuration mismatch.

## Mock interview scoring

- Removed the previous answer-length score, which gave irrelevant long answers a strong result.
- Scoring now measures overlap with expected technical concepts and gives empty or irrelevant answers little or no credit.
- Report breakdown and feedback use the calculated result rather than static high scores.
